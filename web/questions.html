How questions get validated

  1. Submit via GitHub issue using the question proposal template
  2. Cite the exact regulation section (e.g., "45 CFR §164.312(a)(1)")
  3. A reviewer matches it against the source regulatory text
  4. If accurate and not duplicated, it gets merged into the YAML library
  5. The question enters Active status and is used in future scans

All questions include regulatory citations. Proposed questions are reviewed against source regulatory text before being merged.
